# Gurukiran B — Portfolio

## About

A clean, responsive, and performance-optimized personal engineering portfolio for Gurukiran B, a Computer Science Engineering student.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Features

- Responsive design optimized for desktop, tablet, and mobile
- Automatic Light/Dark mode respecting system preferences
- Project showcase with hover states and subtle interactions
- Direct contact links
- GitHub and LinkedIn integration

## Projects

- **Double-Entry Ledger**
- **Carbon-Aware Sustainable Cooling System** (Currently under development.)
- **Traffica**
- **EventTrack**
- **SafeLab Assistant**

## Running Locally

To run the project locally, install the dependencies and start the development server:

```bash
npm install
npm run dev
```

## Production Build

To create a production-ready build, run:

```bash
npm run build
```

## Deployment

The project is built with Vite and React, meaning it is perfectly prepared for deployment on Vercel without any extra configuration.
